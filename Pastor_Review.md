Project Structure Rating - 9/10
  The folder structure and files are organized in a way that is expected from a Blazor app, as well as the names of the files/folders. Codes are organized fairly enough, and commit messages follow the proper conventions of naming commits. Structure of the code can be improved more, but overall, it is a well-managed project given the way the project was built based on the structure.

Front-End Rating - 9/10
  The overall visual of the project is good and cohesive. The photos presented on the login screens were appropriate, displaying the context of the app's main purpose. Labels and icons are sized enough to be readable, and navigation is fairly easy. I also like the current responsiveness of the app, where I can post, upvote, and comment on the main page. I would suggest making those get improved by saving the data in the future, and also to reduce contrast when users click between login and register pages. Overall, there is good front-end experience.
